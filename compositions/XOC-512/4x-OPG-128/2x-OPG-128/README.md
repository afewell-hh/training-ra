# XOC‑512 / 2× OPG‑128 — Variants

Bundles two OPG‑128 units under a spine. Variants mirror the OPG‑128 backend options.
The compositions in this repository are designed to work with air or liquid cooling at any density.

Topology variants
- clos-ro (rail‑optimized backend)
- clos-sh (single‑homed backend)
